DELIVERY GUARANTEE

Database first. Connection second.

  1. Administrator action is committed to SQLite.
  2. A device-specific command is created for each target.
  3. Online agents acknowledge and report results.
  4. Offline jobs stay PENDING until reconnect.

A green delivery indicator never means success. Only an agent’s COMMAND_RESULT marked SUCCESS does.

AUTOMATIC RECONCILIATION

Policy synchronization

Saving a policy and SYNC ALL each create a durable policy version. Online devices receive a SYNC_REQUEST; offline devices retain their assignment and synchronize automatically when registered again.

Actual agent state must match DNS, Chrome and Edge values before a device is marked SYNCED.
