Application Control & Blocking

Enforce which apps can open on this PC. Multi-layered Windows protection (IFEO + DisallowRun + Agent Watcher).

🔒 Locked (View Only)
ⓘ How the OM Agent stops applications from opening:
  • Layer 1 — Image File Execution Options (IFEO): Windows kernel intercepts the executable launch and redirects execution. The application process never starts!
  • Layer 2 — Windows Explorer DisallowRun Policy: Windows displays a system policy message preventing launch via desktop or Start Menu.
  • Layer 3 — Real-Time Agent Watcher: The OM background service terminates any running instances every cycle.
  • Safe Whitelist: Critical Windows processes (explorer.exe, cmd.exe, powershell.exe) and the OM Agent are protected from accidental blocking.

About

OM Client control center for the OM Background Worker and Application Control Engine.

The worker is a headless Windows service that runs at boot (before login), keeps running, and enforces application blocking even if the UI is closed. This UI is the dashboard and rule editor.

  • App Control: Configure blocked and allowed apps with password protection (password: om).
  • Test Phase: Interactively test app blocking on notepad.exe or custom targets.
  • Multi-Layer Blocking: Registry IFEO redirection, DisallowRun Explorer policies, and background watcher.
  • Install worker: Registers the service (auto-start + recovery) and deploys the persistent script.
  • Stop worker: Stops the service and kills any running script/command process.
  • Commands: Run as ADMIN (SYSTEM) or the logged-in USER, in cmd or PowerShell.
  • Windows Firewall is left untouched — no inbound port is opened.
